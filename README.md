# Quack Quack Adventures
### [itch.io page](https://ikuna-games.itch.io/quack-quack-adventures)

**A game where you play as a duck, collecting 'duck treats' to evolve and unlock new abilities.**

## Running the project
Clone the repo, then import the project.godot file using the Godot project manager. *This was made in Godot 4.6.1 STABLE and as such 4.6.1 STABLE is recommended.*
